Visualización de Datos
con Seaborn

3.3.1 Importación y configuración básica

Para utilizar Seaborn, es necesario importar la biblioteca.

import seaborn as sns
import matplotlib.pyplot as plt

3.3.2 Gráfico de dispersión (scatterplot)

Seaborn permite crear gráficos de dispersión de manera sencilla, incorporando automáticamente estilos visuales.

import pandas as pd

data = {
    "Edad": [20, 25, 30, 35, 40],
    "Ingresos": [1000, 1500, 2000, 2500, 3000]
}

df = pd.DataFrame(data)
sns.scatterplot(x="Edad", y="Ingresos", data=df)
plt.title("Relación entre Edad e Ingresos")
plt.show()

Este tipo de gráfico permite analizar relaciones entre variables (James et al., 2021).

3.3.3 Histograma con distribución

Seaborn facilita la visualización de distribuciones mediante histogramas mejorados.

sns.histplot(df["Edad"], kde=True)
plt.title("Distribución de edades")
plt.show()

La opción kde=True permite visualizar la densidad de los datos, lo cual mejora la interpretación.

3.3.4 Gráfico de caja (boxplot)

El boxplot permite identificar la dispersión de los datos y detectar valores atípicos.

sns.boxplot(x=df["Edad"])
plt.title("Boxplot de edades")
plt.show()

Este tipo de gráfico es ampliamente utilizado para detectar outliers (Bruce, Bruce & Gedeck, 2020).

3.3.5 Gráfico de barras

Seaborn también permite generar gráficos de barras más estilizados.

data = {
    "Ciudad": ["Bogotá", "Cali", "Medellín"],
    "Ventas": [200, 150, 180]
}

df = pd.DataFrame(data)
sns.barplot(x="Ciudad", y="Ventas", data=df)
plt.title("Ventas por ciudad")
plt.show()

3.3.6 Matriz de correlación (heatmap)

Uno de los gráficos más útiles en EDA es el mapa de calor para visualizar correlaciones.

corr = df.corr()
sns.heatmap(corr, annot=True)
plt.title("Matriz de correlación")
plt.show()

Este gráfico permite identificar relaciones entre múltiples variables de forma visual (Kuhn & Johnson, 2019).

3.3.7 Ventajas de Seaborn

El uso de Seaborn ofrece varias ventajas:

  • Gráficos más estéticos por defecto.
  • Integración con pandas.
  • Facilidad para representar relaciones estadísticas.
  • Menor cantidad de código.

Estas características facilitan el análisis visual de los datos (Waskom, 2021).

3.3.8 Ejemplo integrado

import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

data = {
    "Edad": [20, 25, 30, 35, 40],
    "Ingresos": [1000, 1500, 2000, 2500, 3000]
}

df = pd.DataFrame(data)
sns.scatterplot(x="Edad", y="Ingresos", data=df)
sns.lineplot(x="Edad", y="Ingresos", data=df)
plt.show()

Este ejemplo muestra cómo combinar diferentes tipos de visualización.
