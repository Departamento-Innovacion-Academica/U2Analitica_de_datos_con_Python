2.3.1 Tipos de valores faltantes

Los valores faltantes pueden clasificarse en diferentes categorías:

  • MCAR (Missing Completely at Random): ausencia de datos completamente aleatoria.
  • MAR (Missing at Random): ausencia relacionada con otras variables.
  • MNAR (Missing Not at Random): ausencia relacionada con el propio valor faltante.

Comprender el tipo de valor faltante permite seleccionar la estrategia adecuada para su manejo (Little & Rubin, 2019).

2.3.2 Identificación de valores faltantes en Python

Pandas proporciona herramientas sencillas para detectar valores nulos.

import pandas as pd df = pd.read_csv("datos.csv") print(df.isnull())

Conteo de valores faltantes por columna:

print(df.isnull().sum())

Esto permite identificar rápidamente qué variables presentan datos incompletos.

2.3.3 Visualización de valores faltantes

También es posible analizar la proporción de valores faltantes.

print(df.isnull().mean() * 100)

Este cálculo muestra el porcentaje de datos faltantes por columna, lo cual es útil para evaluar su impacto.

2.3.4 Identificación de valores no nulos

Para complementar el análisis, se pueden identificar los valores presentes.

print(df.notnull().sum())

Esto permite comparar datos disponibles frente a datos faltantes.

2.3.5 Detección de valores inconsistentes

En algunos casos, los valores faltantes no aparecen como nulos explícitos, sino como valores incorrectos (por ejemplo, cadenas vacías o símbolos).

print(df["Edad"].unique())

Esto permite detectar valores como:

  • "NA"
  • "" (vacíos)
  • Valores fuera de rango

2.3.7 Impacto de los valores faltantes

La presencia de valores faltantes puede generar:

  • Sesgos en el análisis.
  • Pérdida de información.
  • Errores en modelos predictivos.
  • Resultados inconsistentes.

Por esta razón, su identificación es un paso crítico en el análisis de datos (James, Witten, Hastie & Tibshirani, 2021).

2.3.8 Buenas prácticas en la identificación

Para una correcta identificación de valores faltantes, se recomienda:

  • Revisar los tipos de datos.
  • Analizar porcentajes de valores nulos.
  • Identificar valores inconsistentes.
  • Documentar los hallazgos.

Estas prácticas permiten mejorar la calidad del análisis.
