2.5.3 Visualización de relaciones (scatter plot)

El gráfico de dispersión permite visualizar la relación entre dos variables.

Ejemplo:

import matplotlib.pyplot as plt plt.scatter(df["Edad"], df["Ingresos"]) plt.xlabel("Edad") plt.ylabel("Ingresos") plt.title("Relación entre Edad e Ingresos") plt.show()

Este tipo de gráfico permite identificar patrones visuales.

2.5.4 Relación entre variables categóricas y numéricas

Cuando se combinan variables categóricas y numéricas, es posible analizar diferencias entre grupos.

data = { "Ciudad": ["Bogotá", "Bogotá", "Cali", "Cali"], "Ventas": [100, 150, 200, 250] } df = pd.DataFrame(data) print(df.groupby("Ciudad")["Ventas"].mean())

Este análisis permite comparar comportamientos entre categorías.

2.5.5 Análisis multivariable

En muchos casos, es necesario analizar múltiples variables simultáneamente.

print(df.corr())

Esto permite evaluar relaciones entre varias variables al mismo tiempo.

2.5.6 Ejemplo integrado

import pandas as pd import matplotlib.pyplot as plt data = { "Edad": [20, 25, 30, 35, 40], "Ingresos": [1000, 1500, 2000, 2500, 3000] } df = pd.DataFrame(data) # Correlación print(df.corr()) # Visualización plt.scatter(df["Edad"], df["Ingresos"]) plt.show()

Este ejemplo muestra un análisis completo de la relación entre variables.
