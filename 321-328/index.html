3.2.1 Estructura básica de Matplotlib

Matplotlib se basa principalmente en el módulo pyplot, que permite crear gráficos de manera sencilla.

import matplotlib.pyplot as plt

plt.plot([1, 2, 3, 4])
plt.title("Gráfico básico")
plt.show()

Este código genera un gráfico de línea simple.

3.2.2 Gráfico de líneas

El gráfico de líneas se utiliza para representar tendencias a lo largo del tiempo o secuencias ordenadas.

import matplotlib.pyplot as plt

x = [1, 2, 3, 4]
y = [10, 20, 30, 40]

plt.plot(x, y)
plt.title("Gráfico de líneas")
plt.xlabel("X")
plt.ylabel("Y")
plt.show()

Este tipo de gráfico es útil para visualizar cambios en una variable.

3.2.3 Gráfico de barras

El gráfico de barras permite comparar valores entre categorías.

categorias = ["A", "B", "C"]
valores = [10, 20, 15]

plt.bar(categorias, valores)
plt.title("Gráfico de barras")
plt.show()

Este gráfico es común en análisis categórico.

3.2.4 Histograma

El histograma permite analizar la distribución de los datos.

import numpy as np

data = np.random.randn(1000)
plt.hist(data)
plt.title("Histograma")
plt.show()

Este gráfico es útil para observar la forma de la distribución (Wilke, 2019)

3.2.5 Gráfico de dispersión (scatter plot)

El gráfico de dispersión permite analizar la relación entre dos variables.

x = [1, 2, 3, 4]
y = [10, 15, 25, 30]

plt.scatter(x, y)
plt.title("Gráfico de dispersión")
plt.show()

Este tipo de gráfico es fundamental en el análisis de correlaciones (James, Witten, Hastie & Tibshirani, 2021).

3.2.6 Personalización de gráficos

Matplotlib permite personalizar los gráficos para mejorar su interpretación.

plt.plot(x, y, color="red", linestyle="--")
plt.title("Gráfico personalizado")
plt.xlabel("Variable X")
plt.ylabel("Variable Y")
plt.grid(True)
plt.show()

La personalización es clave para una correcta comunicación de resultados (Knaflic, 2015).

3.2.7 Ejemplo integrado

import pandas as pd
import matplotlib.pyplot as plt

data = {
    "Edad": [20, 25, 30, 35, 40]
}

df = pd.DataFrame(data)
df["Edad"].plot(kind="hist")
plt.title("Distribución de edades")
plt.show()

Este ejemplo muestra cómo integrar Pandas con Matplotlib.

3.2.8 Importancia en el análisis de datos

El uso de Matplotlib permite:

  • Representar datos de forma visual.
  • Identificar patrones y tendencias.
  • Mejorar la interpretación de resultados.
  • Facilitar la comunicación de hallazgos.

Según Wilke (2019), la visualización efectiva es clave para transformar datos en conocimiento.
