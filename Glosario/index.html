Glosario de Análisis Exploratorio y Visualización de Datos

Análisis Exploratorio de Datos (EDA)

Proceso inicial de análisis cuyo objetivo es comprender la estructura, características y patrones de un conjunto de datos. Incluye la identificación de valores atípicos, tendencias, correlaciones y distribuciones mediante estadísticas descriptivas y visualizaciones.

Correlación

Medida estadística que indica el grado de relación entre dos variables. En análisis de datos se utiliza para identificar si los cambios en una variable están asociados con cambios en otra.

DataFrame

Estructura de datos bidimensional utilizada en la biblioteca Pandas que permite almacenar y manipular datos en forma tabular, similar a una hoja de cálculo o tabla de base de datos.

Distribución de datos

Forma en que se organizan o dispersan los valores de una variable dentro de un conjunto de datos. Puede representarse mediante histogramas, gráficos de densidad u otros métodos visuales.

Gráfico de barras

Tipo de visualización que representa datos categóricos mediante barras rectangulares cuya longitud o altura corresponde a los valores representados.

Gráfico de dispersión (Scatter Plot)

Representación gráfica que muestra la relación entre dos variables numéricas mediante puntos en un plano cartesiano. Es útil para identificar correlaciones o patrones entre variables.

Histograma

Representación gráfica de la distribución de una variable numérica mediante intervalos o rangos de valores, permitiendo analizar la frecuencia de los datos.

Limpieza de datos

Proceso de detección y corrección de errores, inconsistencias o valores faltantes dentro de un conjunto de datos con el fin de mejorar su calidad para el análisis.

Matplotlib

Biblioteca de Python utilizada para la creación de gráficos y visualizaciones de datos, ampliamente utilizada en análisis exploratorio y presentación de resultados.

Seaborn

Biblioteca de visualización basada en Matplotlib que facilita la creación de gráficos estadísticos más avanzados y estéticamente mejorados para análisis de datos.

Variable categórica

Tipo de variable que representa categorías o grupos, como por ejemplo tipo de producto, región o categoría de cliente.

Variable numérica

Tipo de variable cuyos valores representan cantidades medibles y pueden utilizarse en operaciones matemáticas, como precios, edades o cantidades de ventas.
