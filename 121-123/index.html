  • 1.2.1 Media (promedio)

    La media aritmética es la medida más utilizada y se calcula como la suma de todos los valores dividida entre el número de observaciones.

    Python

    La media es útil cuando los datos están distribuidos de manera uniforme, aunque puede verse afectada por valores extremos.

  • 1.2.2 Mediana

    La mediana corresponde al valor central de un conjunto de datos ordenado. Es especialmente útil cuando existen valores atípicos, ya que no se ve afectada por ellos.

    Python

    La mediana proporciona una representación más robusta en distribuciones sesgadas.

  • 1.2.3 Moda

    La moda es el valor que más se repite dentro de un conjunto de datos.

    Python

    La moda es especialmente útil en variables categóricas.
